# Irbis RFCs

This repository holds Requests for Comments (RFCs) for [Irbis](https://github.com/irbis-sh). RFCs are design proposals for substantial changes to our projects and to how the organisation works. Accepted RFCs live in [`text/`](./text) and form a durable, public record.

## Participation

Anyone is welcome to participate in the process. Please note that all discussion in this repository falls under the [Code of Conduct](CODE_OF_CONDUCT.md).
